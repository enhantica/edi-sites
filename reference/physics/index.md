# Start here

This reference explains the models and numerical conventions used to calculate and fit EasyDiffraction projects. The equations apply across the application, Python and the command line; the [feature matrix](https://easydiffraction.org/user-guide/features/) distinguishes what each interface can do.

## Find a physical model

[Physical models](https://easydiffraction.org/physics/physical-models/) lists each model with the questions it answers, grouped from the diffraction itself to the fit.

## Look up a type or parameter

The [model catalogue](https://easydiffraction.org/physics/models/) lists supported model tokens and their explanations. The [parameter index](https://easydiffraction.org/physics/parameters/) links each scientific parameter to its equation, units and applicable model. [Conventions](https://easydiffraction.org/physics/conventions/) fixes the notation used throughout the reference.

## Use the reference with the assistant

Use a model's exact name and the parameter or equation link when asking a question. The assistant should identify the experiment type and units before applying an equation, distinguish an active parameter from a stored field, and cite the relevant section. Model availability is scoped to the [reference snapshot](https://easydiffraction.org/physics/models/#reference-snapshot).

The [assistant index](https://easydiffraction.org/llms.txt) provides a machine-friendly entry point; the [machine-readable catalogue](https://easydiffraction.org/physics/catalogue.json) identifies model and parameter pages. These are a retrieval source for the assistant, not a claim that chat integration has already been implemented.
