# Start here

This reference explains the models and numerical conventions used to calculate and fit EasyDiffraction projects. The equations apply across the application, Python and the command line; the [feature matrix](https://easydiffraction.org/user-guide/features/) distinguishes what each interface can do.

## Find a physical model

[Physical models](https://easydiffraction.org/physics/physical-models/) lists each model with the questions it answers, grouped from the diffraction itself to the fit.

## Look up a type or parameter

- The [model catalogue](https://easydiffraction.org/physics/models/) lists the supported model types and what each one does.
- [Parameter explanations](https://easydiffraction.org/physics/parameters/) link each scientific parameter to its equation, units and model.
- [Conventions](https://easydiffraction.org/physics/conventions/) fix the notation used throughout this reference.

## Ask an AI assistant about the physics

The application's [built-in assistant](https://easydiffraction.org/user-guide/ai-assistant/) and your own assistant can both read this
reference. When you ask a question, name the model and link the parameter or equation; a good answer states the
experiment type and the units before it applies an equation.

Your own assistant can start from the [assistant index](https://easydiffraction.org/llms.txt) and the
[machine-readable catalogue](https://easydiffraction.org/physics/catalogue.json), which list every model and parameter page.
